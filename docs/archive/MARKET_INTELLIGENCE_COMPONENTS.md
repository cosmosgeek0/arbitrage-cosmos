# Market Intelligence Component Manifest

This manifest describes the bounded library delivered under `server/src/intelligenceFoundation/**`. Every production component is pure or injected-clock/injected-data driven. None is wired to a route, socket, timer, exchange client, account action, proposal queue, risk gate, ledger, or execution path.

## Authority boundary

Existing Basis and Volume engines remain the only strategy authorities. The existing ledger, risk, control, reconciliation, replay, and execution systems retain their current ownership. The delivered library supplies evidence, resource plans, explanations, immutable pre-event records, outcomes, and a static read model only.
