# F13 DecisionLab limitations

1. **No recorded decision fixture exists.** The abstained and missed-opportunity fixtures are explicitly unverified recorded-shape fixtures. They prove validation behavior only; they contain no accepted owner record bytes.
2. **No counterfactual policy payload exists.** The six Q alternatives have metadata-only owner references. The L execution-policy row binds only a type and fixture-factory source; it is not a materialized or evaluated candidate.
3. **No alternative behavior is reported.** All seven outcomes and all eight ablation baselines/variants are `UNAVAILABLE`. MFE, MAE, exposure time, realized/hypothetical costs, uncertainty quantities, and residual-liability amounts remain null where owner evidence is missing.
4. **No causal or off-policy estimate is supportable.** Logging-policy probabilities are unavailable, support/overlap is unproved, and this is a one-decision descriptive contract. IPS, doubly robust, SWITCH, or causal estimates are not run.
5. **Synthetic predeclaration is not historical proof.** The seven-item local manifest freezes scenario grammar for tests only. Its time is non-authoritative and cannot show that an alternative existed before a real decision.
6. **Q15 is synthetic experiment metadata only.** The lossless adapter proves contract compatibility; it does not create a Q registry record, treatment, exposure, outcome, promotion, or policy.
7. **Owner version wording is local where necessary.** Main/L values such as `accepted-main@f0168cb` and `L08ExecutionPolicyCandidate@1` are DecisionLab-local frozen aliases, not exported owner version literals. The actual owner type/schema, full Git ref, commit, and file SHA-256 control provenance.
8. **No portable JSON Schema is claimed.** Closed runtime validators are tested; a stale or permissive schema was intentionally omitted rather than presented as equivalent proof.
9. **No host resource envelope is measured.** CPU, RSS, disk, throughput, latency, queue, and storage-growth claims remain unavailable because nothing is mounted. Only structural input limits and zero network/model use by design are enforced.
10. **The preview is not a cockpit surface.** It is local, read-only, fixture-only, unmounted, non-canonical, contains no controls, and has no health, attention, routing, or deployment authority.
11. **No external effects exist.** There is no network transport, credential access, environment access, persistence, timer, randomness, product import, order path, mutation, mount, wire, deploy, or shared edit.

These limits block `PRESTAGE_READY`. A green focused test suite proves the scaffold fails closed; it does not prove Section 9G's owner-dependent capability.
