Deduplication and inability to proceed are separate `disposition` values, not extra lifecycle states:

Terminal accounting is exact:

| Outcome | Required accounting |
|---|---|

| Proposed organ is unsafe or redundant | keep the last honest build state, `disposition: REJECTED` |
| Conditional organ has no proved gap | `buildState: PLANNED`, `disposition: NOT_LAUNCHED` |

Names such as `FRONTIER_CONTRACT_READY` or `VENUE_MESH_PRESTAGE_READY` may appear only as human-readable `terminalLabel` values in receipts. They never replace `buildState` or create a second state machine.

## 15. What this program can and cannot achieve

Frontier can:

- use spare model capacity without colliding with the active candidate;
- build substantial optional product capability now;
- reduce later implementation effort;
- establish removable plug-in seams;
- provide new senses, simulation, research, and operator training;
- let failed optional work be discarded without harming the accepted product.

Frontier cannot:

- accelerate the serial critical-path repair and independent-verification chain;
- prove the existing product correct;
- prove a market edge;
- guarantee profit;
- safely predict the final integration cost before the accepted SHA exists;
- make untested prestage code part of the product;
- eliminate the need for real forward evidence.

The honest day-one Q state may remain `DATA_INSUFFICIENT` or `ABSTAIN_UNKNOWN`. More organs do not manufacture evidence that has not happened yet.

## 18. Definition of success

This program is complete when:

- F0 has one frozen, tested extension contract;
- every launched module has one valid `buildState` and a disposition of `ACTIVE`, `ALREADY_OWNED`, `BLOCKED`, `REJECTED`, or `NOT_LAUNCHED` with exact evidence;
- all artifacts are isolated, deterministic, tested, documented, and recoverable;
- no product/core/shared file was edited;
- no live network, credential, infrastructure, or money action occurred;
- every module can be discarded without affecting the active candidate or accepted Main;
- the future insertion work is precise and bounded;
- the Frontier board matches Git;
- no claim exceeds measured truth.

The correct final sentence is:

> The optional organs are built and parked. The accepted product is unchanged. Each organ has prestage compatibility evidence, exact limitations, and a bounded future port request. No production socket or runtime safety claim exists until independent post-mount proof.
