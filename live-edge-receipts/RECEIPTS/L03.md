## Delivered behavior

- Exact signed-contract resolution accepts only current, production, REST,
  signed Spot or USD-M contracts from the literal-locked L02 matrix. Free-form
  hosts, paths, realms, products and signer substitutions fail closed.
- Unsigned construction is independently inspectable. Signed construction
  repeats every gate from raw caller input and never accepts prepared payload
  bytes.
- Parameters use bounded query-only RFC 3986 encoding, deterministic code-point
  name ordering and exact decimal strings. Duplicate, reserved, sensitive,
  credential-shaped, accessor, proxy, control, bidi, surrogate, percent,
  count and byte-limit inputs fail before signing.
- The call-scoped HMAC signer receives only canonical bytes, owns no key in this
  module and cannot leak thrown causes, stacks or invalid output. Public
  illustrative Spot and USD-M HMAC vectors pass without real credentials.
- Order construction delegates client-order identity to the existing
  Foundation owner. Per-order cancel requires an exact canonical
  `origClientOrderId`; it never derives a new one. Identity-free cancel-all and
  countdown-cancel contracts are mechanically unconstructable.
- Local transport request identities are deterministic and domain-separated,
  accept the exact Foundation correlation form and are not commands, plans,
  tickets, events or durable identities.
- The pure clock estimator uses three through nine injected UTC/monotonic
  samples, median offset, 250 ms outlier rejection, 100 ms fresh dispersion,
  bounded RTT, freshness and explicit unavailable/stale/skewed states. It
  reads no clock and schedules nothing.
- V2 rate state consumes only exact L02 source/cost/dimension claims, always
  quotes the worst accepted conditional cost and keeps endpoint cost separate
  from caller-supplied capacity evidence. Missing capacity or an unprimed
  header baseline remains unknown.
- Header chronology cannot regress or erase local reservations. Reservations
  across request-weight and order-count dimensions are atomic. Spot 429
  cooldowns never shorten, including unaligned later observations; 418 remains
  manual. USD-M unknown cooldown timing remains blocked.
- Automatic retry advice is bounded to eligible read-only contracts and exact
  rate-state proof. Mutations, test orders, cancels, Margin, private-stream
  controls and ambiguous outcomes always block automatic retry.
- The immutable ambiguity reducer accepts only exact L03 request-ID and
  Foundation-derived client-order-ID forms. Timeout, disconnect, 408, 5xx,
  abort, malformed and incomplete outcomes preserve `UNKNOWN`, require later
  reconciliation and mechanically block duplicate submit.
- A terminal-evidence reference is only a neutral hand-off candidate; it does
  not claim canonical status and cannot clear ambiguity. L03 creates no
  execution lifecycle event, reconciliation result or durable store.
- Failure construction reuses the Foundation structured-failure owner.
  Recursive public diagnostic projection keeps only bounded allowlisted facts
  and drops signed/unsigned material, credentials, signatures, URLs, account
  values, causes, stacks and credential-shaped opaque identifiers.
- Static and runtime purity tripwires prove no network, filesystem, environment,
  timer, wall clock, randomness, key API, existing exchange client, Foundation
  execution/reconciliation or global mutable-registry seam.
