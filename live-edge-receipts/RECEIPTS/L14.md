## Surviving implementation

- One closed 18-action discriminated command set covers desired state,
  pause/resume, bounded config, approval/arm/disarm/re-arm/revocation, halt,
  reconciliation, cancel, close/reduce, precomputed recovery, repayment, safe
  restart and awareness acknowledgement.
- Every request/action/reference/value has an exact bounded runtime schema.
  Generic payload bags, inherited/accessor/symbol fields, unsafe text,
  secret-shaped material, arbitrary remote/shell text and client actor fields
  fail before authority or persistence calls.
- Actor identity is resolved only through the injected authenticated operator
  port and committed as a server-derived session binding.
- Server-minted preview ID, canonical action/preview digests, authorization
  tag, expected config/control versions, risk witness and expiry are all bound.
- The injected persistence port must commit the exact intent and atomically
  reserve the optimistic global control revision before owner publication.
  Exact ACK validation binds event/request digest, idempotency key,
  per-command version/head, Ledger event ID, commit time and current versions.
- Exact completed and terminal-rejected commands replay their original result
  without another owner call. Foreign digest, actor, config/action or reserved
  revision fails closed. Pre-intent security audits do not reserve the
  authentic command ID.
- Owner throw, malformed result, post-intent expiry, failed terminal append or
  otherwise uncertain publication retains a pending durable intent and returns
  `COMMAND_OUTCOME_UNCERTAIN`.
- Foundation Control Plane rejections retain closed exact mappings for stale,
  reused, in-progress and not-applicable outcomes across durable replay.
- `CANCEL`/`CLOSE` and other risk-bounded recovery actions re-read injected
  exchange truth and canonical Foundation Risk. The same risk definition,
  revision and current value are bound at preview, and final projected exact
  decimals may not exceed current or predeclared maximum risk.
- `ACKNOWLEDGE_RECOVERY` records awareness only with
  `recoveryStateChanged=false`; it never clears recovery truth.
- Only the exact existing Foundation `control-plane-runtime` lifecycle command
  seam is adapted. Other canonical owners are injected structural ports; no
  owner or local store is duplicated.

All events and receipts retain `externalActionAuthorization=NONE`.
