## Delivered boundary

Q16 adds one deterministic, advisory-only local process:

1. An exact `Q16RawInferenceFixtureV1` sourced from the accepted Q04 Spot replay.
   Source event and receive time come from Q04 steps; consumed events must precede
   receive, cutoff and generation.
2. A frozen `MarketEvidenceEnvelopeV1` and five feature values produced by existing
   Q06/Q07 owners. Q16 does not duplicate book or feature semantics.
3. An exact serving manifest over accepted Q04/Q06/Q07/Q12/Q13/Q15 evidence, the
   dependency lock, complete imported Q06/Q07 source closure and all eight Q16
   inference source files. Artifact type, media, path, schema, version, byte length
   and digest must match current verified bytes.
4. Opaque field-bound serving lineage. Ordinary mutation, copying or dataclass
   replacement cannot turn accepted non-loadable/abstaining lineage into
   `AVAILABLE`, `ADVISORY`, calibration-ready or deep-pass truth.
5. A six-stage deterministic chain: `RAW`, `EVIDENCE`, `FEATURES`, `MODELS`,
   `CALIBRATION`, `ASSESSMENT`. Every stage SHA-256 binds its immediate parent.
6. A frozen `EdgeAssessmentEnvelopeV1` with `ABSTAIN_UNKNOWN`, empty predictions,
   no score, no calibrated probability, `UNKNOWN` net economics, explicit blockers,
   and `DEGRADED` health. Safe-abstention serviceability is separate from advisory
   readiness.
7. Local operations for assessment, bounded batch, health, readiness, lineage and
   metrics. Concurrency one, application queue wait, execution time, handler count,
   bytes and rows are bounded. Timed-out work is quarantined behind the semaphore
   until it finishes and cannot publish a late response or completion metric.
8. Permissioned UDS transport and optional literal-loopback TCP. UDS startup never
   removes a race winner; shutdown cleans only the captured matching device/inode.
9. Strict generated Python and Node clients. Raw request file/byte calls preserve
   accepted nanosecond integers. Responses have strict UTF-8/JSON, duplicate,
   number, size, timeout, forbidden-key, full frozen-schema and fail-closed semantic
   validation.

There is no listener outside UDS/literal loopback, streaming claim, model loader,
environment read, secret, external network source, private/signed exchange call,
order, test order, borrow/repay, transfer, withdrawal, leverage/margin, capital,
risk, promotion or execution authority. `LIVE_EXECUTION_NOT_IMPLEMENTED` remains
untouched.

## Adversarial review and corrections

Independent reviews repeatedly attacked the implementation. Every reproduced issue
was corrected and retained as a regression:

1. JavaScript rounding of committed nanosecond request integers was removed with
   raw file/byte APIs; unsafe object integers reject.
2. Python/Node boolean, integer and float acceptance was aligned over an explicit
   cross-language-safe numeric subset.
3. A failed UDS bind can never unlink a foreign race winner; cleanup requires the
   captured matching device/inode.
4. Artifact ID/digest-only checking was replaced by exact metadata/current-byte
   verification. Q06/Q07 and Q16 code identity are pinned.
5. Secret/order keys using spaces, dots, slashes or mixed separators reject at any
   depth.
6. Protocol-kit inventory is exact, includes Markdown and a wrapped response, and
   excludes only its self-referential manifest.
7. Caller cutoff and request generation time cannot rewrite accepted Q04 source
   event/receive truth. Trusted evaluation time is injected per request.
8. Direct queue APIs that bypassed correlation/concurrency were removed. The single
   worker boundary, bounded wait, execution deadline and pre-frame handler bound are
   exercised through real UDS traffic.
9. Late inference cannot return after deadline or release concurrency early. It is
   quarantined without publishing completion/abstention state.
10. Lineage construction is exact-current and opaque. Mutable/copyable seal attacks,
    ordinary dataclass replacement and boolean nested artifact versions fail.
11. Metrics are lock-protected and include actual wait depth, timeout, transport,
    saturation and closed-state counters. Oversized responses never count complete.
12. Generated clients reject duplicates, non-finite values, forbidden keys,
    malformed nested assessments, actionable ambiguity, false-green health,
    malformed protocol errors and non-integer metrics.
13. Closing the owned handle stops `serve_forever`, closes the service even when
    cleanup detects replacement, and performs identity-safe socket removal.
