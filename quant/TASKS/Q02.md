## Code and evidence artifacts

- Typed `quant_edge` lake/contracts modules with no import-time I/O, environment, wall clock, randomness, timer/thread or network behavior.
- One versioned canonical row/schema contract for a small synthetic reference partition. Preserve venue/product/symbol/instrument version, event/receive times, sessions/sequences, raw hash, quality flags and exact scaled/decimal values without fabricated defaults.
- Pure deterministic Arrow/Parquet encoder plus reader/validator. Fixed schema/metadata/order/row-group/writer settings; identical canonical input must yield identical bytes on the Q01 lock.
- Canonical manifest/provenance model with dataset/revision/schema identities, partition key/path, byte/row count, schema fingerprint, time/session bounds, quality counts, parent hashes, code/config identity and retention class.
- Immutable filesystem commit boundary that rejects overwrite/path escape/symlinks, treats manifest-last publication as commit, detects incomplete revisions and never silently repairs corruption.
- Explicit quality-state engine using `COMPLETE`, `PARTIAL`, `GAPPED`, `STALE`, `RECONSTRUCTING`, `SAMPLED`, `UNAVAILABLE`, `SYNTHETIC`, `UNKNOWN`; unavailable is never zero.
- Exact scaled-integer/decimal primitives with units/bounds and lossless Arrow round trips; floats are forbidden at the contract boundary.
- Hardened DuckDB helper that accepts only already-validated Arrow tables, disables external access and extension auto-install/autoload, uses bounded single-thread generated queries and returns explicit deterministic ordering.
- Versioned `DataSourceCard` admission contract covering launch Q-C gates. Q02 admits no external source.
- Separate immutable owner-annotation contract covering visible-at-tag evidence, outcome visibility/blinding, timestamp/schema version/tags/rationale and later objective-outcome linkage. It never overwrites objective labels or authorizes action.
- Golden/property/contract tests and current research/decision documentation.
