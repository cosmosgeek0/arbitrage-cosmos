## Code and evidence artifacts

### Official archive import

- Pure bounded importer contracts that accept caller-supplied ZIP bytes, official checksum bytes and explicit provenance; library code performs no network, environment or ambient-time access.
- Exact SHA-256 sidecar verification before extraction; bounded archive/member counts, compressed/uncompressed sizes and ratios; one regular expected CSV member; no traversal, symlink, duplicate-name, encrypted or nested archive behavior.
- Versioned schema adapters only for the selected proven archive family. Preserve raw timestamp integer, explicit per-file unit/basis, exact numeric strings/scales, raw row/member/archive hashes and invalid-row evidence.
- Reject headers/schema drift, malformed CSV, floats/noncanonical numerics, impossible dates, mixed same-column units, duplicates and repaired invalid markers from economic rows. Never convert invalid zero/`-1` repair markers into trades.
- Canonical deterministic normalization into accepted lake contracts and a new immutable revision. Acquisition/retrieval time is injected and recorded, never read from wall clock.
- A real bounded official public sample is fetched explicitly outside deterministic tests, verified against its official sidecar, imported into a temporary lake, and summarized in a committed immutable evidence receipt. Do not commit raw licensed ZIP/CSV or derived row-level market data while redistribution permission is unresolved.

### Coverage and revision evidence

- Machine-readable and human-readable product/event/date capability matrix with URL, retrieval time, official sidecar checksum, retrieved artifact/member hashes, byte/row counts, schema fingerprint, raw unit/basis, first/last source time, gap/invalid/duplicate counts, archive revision/replacement status and known omissions.
- Missing archive paths/files are `UNKNOWN/UNAVAILABLE`, not zero coverage.
- Record that archive history lacks local receive clocks, full sequenced L2, queue position, live latency, complete liquidation flow, borrow truth and causal intent.
- A URL whose official checksum changes creates a new immutable source/lake revision; no in-place rewrite.

### Forward capture seam

- Versioned, pure read-only bridge envelope/adapter interfaces and synthetic fixtures shaped from the existing canonical runtime/MI owners. No network/client/storage effect is implemented.
- Preserve nullable source event/trade/update time, local receive wall and monotonic clocks, processing/persistence times, connection generation, receive ordinal, session/stream IDs, sequences, raw hash and quality/gap/drop/restart evidence.
- Introduce a separate versioned nullable-source-time lake schema with an explicit deterministic partition/order clock basis. Spot book ticker without `E/T` retains null source time and uses declared receive-wall ordering; it never impersonates exchange event time.
- Product/event schemas remain distinct. Spot `U/u` and USD-M `U/u/pu` evidence may be represented, but Q03 does not reconstruct a book or implement Q04 overlap/resnapshot logic.
- A bounded queue/drop contract proves Q capture cannot backpressure the operational owner. Real bridge status remains `MISSING/BLOCKED` until integration acceptance.
- Optional Tardis adapter is a typed capability interface/card only; no dependency, credential, subscription, download or raw redistribution.

### EventAtlas bootstrap

- One canonical machine-readable `EventAtlas` registry and deterministic Markdown projection, versioned and explicitly research-only.
- Two tier descriptors exist from inception: `HISTORICAL_COARSE` and `FORWARD_HIGH_FIDELITY`.
- The historical tier binds the real imported-sample revision/coverage receipt. The forward tier binds only synthetic bridge contract fixtures and reports real coverage `MISSING/BLOCKED`, never synthetic as market evidence.
- Add multiple versioned absolute and volatility/liquidity-relative candidate-discovery rule descriptors; do not define an event as only `25%/24h` and do not claim thresholds are truth.
- Materialize the bounded sample's candidate/control window inventory. Zero candidates is valid if the rules do not fire; counts, symbol/product/date coverage, gaps, invalid rows, controls and missing later outcomes must be reported exactly.
- Each bootstrap record binds available pre-window/evolution evidence, source coverage, point-in-time observed instrument identity and economics posture. Later outcomes/labels not yet supported remain `UNAVAILABLE`; Q03 does not implement Q05 label generation or owner-annotation records.
- No score is `P(bait)`, calibrated probability, profitability, causal intent or actionability. Existing H5/Q-D challenger limits remain unchanged.
