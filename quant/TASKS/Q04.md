## Purpose

Build the deterministic Spot and USD-M local order-book reconstruction reference model over
exact-decimal depth evidence: the product-specific snapshot/delta sequence law, gap and
resynchronization state machine, explicit exchange/receive/processing clock separation,
late/duplicate/out-of-order/reconnect handling, and byte-identical deterministic replay.
Q04 creates no production socket, REST poller or snapshot loop; snapshot acquisition is a
typed request intent addressed to the canonical runtime boundary. Real forward depth
delivery remains `MISSING/BLOCKED` from Q03, so every executable Q04 proof runs on
synthetic or replayed fixtures that are honestly labeled and never presented as observed
market evidence. Q04 implements no Q05 label factory, features, models or action authority.

## Code artifacts

New package `quant/src/quant_edge/book/`:

- **Depth evidence contracts.** Versioned exact-decimal level, delta and snapshot types:
  Spot deltas carry `U/u` and event time `E`; USD-M deltas carry `U/u/pu`, event time `E`
  and transaction time `T`; snapshots carry `lastUpdateId` (plus `E/T` for USD-M), full
  bid/ask arrays and injected acquisition clocks. Every input preserves receive wall and
  monotonic clocks, receive ordinal, connection generation, session/stream identity,
  posture (`SYNTHETIC`/`REPLAY` only in Q04) and bounded sizes. Prices/quantities are
  exact scaled decimals; floats and noncanonical numeric strings are rejected.
- **Price ladder.** Deterministic sorted bid/ask ladders with absolute-quantity
  replacement, zero-quantity removal, removal-of-absent-level counted as normal per the
  official law, bounded level counts, and crossed-ladder detection.
- **Product state machines.** One reconstructor per product implementing the official
  sequence law exactly: buffering before sync, stale-snapshot rejection and retry intent,
  buffered-overlap replay, first-event bridge bounds, per-product continuity
  (`U == prev_u + 1` for Spot; `pu == prev_u` for USD-M), and fail-closed transitions.
  Any continuity violation, crossed book, invalid snapshot, buffer overflow or reconnect
  discards local state, marks the book `GAPPED`/`RECONSTRUCTING`, stops model-eligible
  emission, emits a typed snapshot request intent and a quality transition event, and
  restores `COMPLETE` only after a full validated resynchronization. Anomalies are
  classified (duplicate, overlap, regression, forward gap, reconnect, overflow, crossed,
  invalid snapshot) as evidence; classification never weakens the fail-closed law.
- **Clock truth.** The engine reads no ambient time, environment or randomness; all
  exchange/receive/processing clocks are injected. Transitions and applied events carry
  the full clock evidence and a monotonic engine step counter.
- **Deterministic replay.** A pure replay runner that consumes a fixture event/snapshot
  script and emits a canonical, hashable result (final ladders, transition log, applied /
  dropped / buffered / anomaly counts). Identical scripts produce byte-identical results
  across process, CWD, timezone and hash-seed changes.

Evidence artifacts: one committed golden replay fixture under `quant/fixtures/` and
hash-bound generated replay/campaign evidence under `quant/generated/q04/`; a decision
note `quant/DECISIONS/Q04-001-LOCAL-BOOK-TEMPORAL-TRUTH.md`.

## Acceptance conditions

- Both product reconstructors implement the official documented algorithms with exact
  research-pinned citations; product laws remain distinct and are never blended.
- Gap campaigns never emit an actionable `COMPLETE` book before a validated
  resynchronization; model-eligibility is provably false in every non-`COMPLETE` state.
- All clocks are injected and separated; no receive clock impersonates exchange time.
- Replay is deterministic and byte-identical across hostile environment changes.
- All fixtures are honestly `SYNTHETIC`/`REPLAY`; nothing claims observed market depth,
  and real forward delivery remains recorded as `MISSING/BLOCKED`.
- Focused/property/case-matrix/safety/accumulated tests and independent adversarial
  review pass; immutable `quant/RECEIPTS/Q04.md` exists in implementation commit C4; a
  later independently verified acceptance commit A4 records C4 and advances state.
