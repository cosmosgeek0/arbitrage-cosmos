## Purpose

Build the deterministic Section 11 label and outcome factory: point-in-time sample
identity, multi-horizon numeric outcomes with honest censoring, versioned stage labels,
Basis label contracts, event disposition labels, matched non-event controls and the full
§11.7 leakage/reproducibility test law, wired to the accepted Q03 Event Atlas windows and
the Q02 evidence rows, with objective-outcome linkage that the accepted Q-E
owner-annotation contracts can reference. Every generator is exercised end to end on
deterministic synthetic fixtures; real-data coverage is computed only where the accepted
bounded sample lawfully supports it and everything else is explicitly
`UNAVAILABLE`/`DATA_INSUFFICIENT`, never zero. Q05 implements no feature registry, model,
calibration, drift, inference or action authority.

## Code and evidence artifacts

New package `quant/src/quant_edge/labels/`:

- **Point-in-time sample identity (§11.1).** A versioned sample record carrying sample
  ID, event/cohort ID, symbol and instrument identity, feature cutoff time, label
  start/end, horizon, feature lookback interval, source completeness interval, and
  dataset/feature/label/cost/execution-assumption versions. Identity is
  content-derived and deterministic; feature cutoff strictly precedes label start; no
  field may silently default.
- **Multi-horizon numeric outcomes (§11.2).** A pure engine over event-timestamped
  evidence series computing, where the supplied series lawfully supports them: future
  mid/return outcomes at the required horizon grid (1s, 5s, 15s, 30s, 60s, 5m, 15m, 1h),
  MFE/MAE with time-to-MFE/MAE, first-passage to explicit relative barriers, and gross
  versus conservative net outcomes under explicit versioned cost scenarios. Executable
  bid/ask, spread/depth deterioration, opportunity decay and capacity outcomes exist as
  typed contracts that report `UNAVAILABLE` without book/quote evidence; the historical
  aggTrades sample supports trade-mid proxies only and must say so. Right-censoring is
  explicit (`CENSORED`, with censor time), never coerced to a value.
- **Stage labels (§11.3).** The exact ten-state stage vocabulary generated only by
  versioned threshold descriptors over observable evidence; `UNKNOWN`/`NO_EVENT` are
  honest defaults; no API permits post-hoc relabeling of a sealed sample.
- **Basis labels (§11.4).** Typed normal/reverse Basis label contracts (entry basis,
  max executable net edge, convergence path/time, right-censored non-convergence,
  funding/borrow/fee/slippage/recovery assumptions, feasibility) computed only from
  supplied dual-leg fixture series; with no derivatives evidence in the lane, real
  coverage is `DATA_INSUFFICIENT` and recorded as such.
- **Event disposition labels (§11.5).** `ACTED/REJECTED/EXPIRED/MISSED/QUIET_CONTROL/
  DATA_INVALID` retained on every atlas-linked cohort; gapped/incomplete evidence maps
  to `DATA_INVALID`, never a normal negative.
- **Matched controls (§11.6).** Deterministic matching of non-event windows by symbol,
  liquidity/activity bucket, volatility regime bucket, time-of-day/funding-cycle
  context and data completeness, with hard non-overlap against the event's feature and
  label intervals and no future-membership leakage into eligibility.
- **Outcome linkage (Q-A/Q-E).** Label records bind atlas window IDs and are
  referenceable by the accepted owner-annotation outcome-link contract; a synthetic
  end-to-end fixture proves the linkage without creating any annotation authority.

Evidence artifacts: committed golden label fixture(s) under `quant/fixtures/`,

- Controls are reproducible, matched on the §11.6 axes and non-overlapping with event
  feature/label intervals.
- All outcome/stage/Basis/disposition semantics follow the directive vocabularies
  exactly; unknown stays unknown; unsupported evidence yields `UNAVAILABLE`/
  `DATA_INSUFFICIENT`/`DATA_INVALID`, never fabricated numbers.

  independent adversarial review pass; immutable `quant/RECEIPTS/Q05.md` exists in
