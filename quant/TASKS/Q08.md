## Code and evidence artifacts

New package `quant/src/quant_edge/derivatives/` (library modules inert: no env, no
network, no ambient clock, no filesystem, no floats in public numeric contracts):

- **References kept distinct.** `ReferenceKind` (LAST_TRADE/MID/MARK/INDEX) with a
  typed reference set carrying per-kind knownness; premium (mark vs index) and each
  cross-kind difference computable only from its own declared kinds; no substitution,
  no silent mixing, and indicative (mid/last) basis types remain distinct from
  executable basis types.
- **Executable Basis, both constructions.** Sized two-sided quote contracts; NORMAL
  (buy Spot at ask, sell perp at bid) and REVERSE (sell Spot at bid, buy perp at ask)
  entry basis computed only from crossed executable sides at an explicit intended
  size; size feasibility explicit; REVERSE feasibility requires known borrow per the
  accepted Q05 law; net-of-cost edge exists only when every cost component is known.
- **Cost stack with knownness.** Versioned per-component cost stack
  (per-leg fee, entry/exit slippage, funding carry, borrow carry, recovery); a total
  exists only when all components are KNOWN; any UNKNOWN component makes the total
  UNKNOWN, never zero.
- **Funding features.** Funding evidence with schedule; level/change,
  time-to-next-funding against an injected as-of clock, schedule-interval change
  detection; missing funding is UNKNOWN, never zero.
- **Open interest.** Sampled OI evidence series; level/change/acceleration and the
  price/OI quadrant (four states plus UNKNOWN) with explicit staleness law.
- **Liquidation context.** Liquidation evidence whose quality is structurally confined
  to SAMPLED/PARTIAL/UNKNOWN (the official stream semantics cannot prove
  completeness); windowed count/notional context that never claims COMPLETE.
- **Borrow knownness.** Features over the accepted `BorrowAssumptionV1`:
  knownness projection and hourly-rate value that is AVAILABLE only under
  KNOWN_AVAILABLE; UNKNOWN and KNOWN_UNAVAILABLE never produce a zero rate.
- **Basis path and leg attribution.** A dual-leg basis path built from Q05
  `EvidenceSeriesV1` legs with explicit staleness/gap law; per-observation leg
  attribution (which leg caused each basis change, exact shares); wall-time basis
  bars in the frozen `BarSeriesV1` shape with a documented alignment convention.
- **Registered bar features (frozen Q06 law).** At least four derivative feature
  cards — basis gap velocity, gap acceleration, sign persistence, converging fraction
  — each with the complete `FeatureCardV1`, exact batch reference, streaming
  implementation and golden vectors proven under the frozen `run_equivalence`
  harness within declared integer-ulp tolerances.
- **State-space challenger.** Deterministic fixed-gain scalar latent fair-basis
  filter (versioned, REFERENCE_ONLY challenger, explicitly not a validated model)
  with innovation truth; exact-rational AR(1) coefficient diagnostic and discrete
  mean-reversion half-life bracketing in exact integer arithmetic; non-mean-reverting
  and insufficient-history cases stay UNKNOWN.
- **Convergence estimation and target support.** Half-life estimate from an entry
  observation to the versioned threshold crossing with an explicit uncertainty
  bracket (previous-observation/crossing-observation interval); right-censoring at
  the horizon; `ConvergenceTargetV1` censored duration targets (per construction)
