deterministic pure library: two-sided CUSUM, Page-Hinkley, offline PELT segmentation,

## Code and evidence artifacts

New package `quant/src/quant_edge/regime/`:

- **Observation contract.** A bounded, time-ordered `ObservationSeriesV1` over
  `FixedPointV1` values with per-point `QualityState`; posture `SYNTHETIC`/`REPLAY`
  only. Quality gates fail closed: ineligible points update no detector state; gap-class
  quality resets sequential detectors and the reset is visible in the step record.
- **Two-sided CUSUM (§13.4).** Streaming upper/lower cumulative sums against an explicit
  reference law (fixed target or documented warmup mean), slack `k` and threshold `h` in
  value units; typed step records with direction, statistic and alarm; deterministic
  restart-after-alarm law.
- **Page-Hinkley (§13.4).** Two-sided PH statistic against the exact running mean
  (integer mean quantized half-even per step), magnitude `delta` and threshold
  `lambda`; same step/alarm/reset law as CUSUM.
- **Offline PELT (§13.4).** Optimal-partitioning dynamic program with PELT pruning over
  a declared quantized SSE cost (exact integer arithmetic after one documented half-even
  quantization per segment cost), explicit penalty and minimum segment length, bounded
  input size; returns typed segments with boundaries, quantized means and costs. The
  quantized cost is the objective; the DP is exact for it.
- **BOCPD with bounded run length (§13.4, Adams–MacKay).** Observations are discretized
  into a bounded alphabet by robust median/MAD thresholds; the per-run-length predictive
  is the exact Dirichlet-categorical rational; the run-length posterior is fixed-point
  with a documented largest-remainder normalization law and a hard run-length cap whose
  tail mass folds into the cap bin; typed step records expose the posterior, MAP run
  length, change mass and alarm.
- **Soft regime behind a stable interface (§13.4/§14.6).** A `RegimeModel` protocol and
  a deterministic recursive Bayesian filter over a fixed state set with fixed-point
  transition matrix and per-state emission tables over the same alphabet; probability
  floor prevents unseen-regime overconfidence; outputs per-state probabilities (exact
  fixed-point normalization law), MAP state and an uncertainty measure; `UNKNOWN` when
  warmup/quality forbids a value. A v1 joint volatility/activity spec proves the
  machinery; its tables are machinery constants, not market truth.
- **Robust anomaly + disorder/OOD state (§14.5 baseline, §13.4).** Rolling median/MAD
  anomaly score (MAD units, explicitly `UNCALIBRATED_SCORE`), threshold exceedance and
  persistence runs; a joint disorder state (`NORMAL`/`WATCH`/`DISORDERED`/`OOD_SUSPECT`/
  `UNKNOWN`) fused worst-of from changepoint recency, anomaly persistence, regime
  uncertainty and quality, with reason codes.
- **Earlier-only Matrix Profile (§14.7).** Left matrix profile over bounded fixed-point
  series: for each window, the best strictly earlier, non-overlapping, non-same-event
  window under the z-normalized distance ordering, computed by exact integer
  correlation-order comparisons (signed ρ² cross-multiplication; no floats, no square
  roots); similarity reported as half-even-quantized signed ρ²; degenerate windows and
  empty candidate sets degrade to explicit `None`; excluded candidates are counted by
  reason (`FUTURE`, `OVERLAP`, `SAME_EVENT`, `DEGENERATE`).
- **Earlier-only analog retrieval (§14.7).** Top-`k` retrieval over registered analog
  records with symbol/regime cohort filters, cutoff/embargo law (a record is eligible
  only when its window ends at or before the query cutoff minus embargo), overlap and
  same-event exclusion, deterministic tie-breaks, and a typed result carrying neighbors,
  similarity, cohort size, exclusion counts by reason, outcome distributions (exact
  counts, never cherry-picked examples) and completeness; no close analogue degrades
  gracefully to an explicit empty state.
- **Detection metrics harness (§13.4 acceptance).** Typed evaluation of alarms against
  planted truth: false-alarm count/rate (exact ratios), per-change detection delay,
  missed changes, mean/max delay, plus segmentation boundary error for PELT and
  hit/false rates for anomaly/OOD injection; a declared budget contract turns
  measurements into pass/fail truth.
- **Deterministic campaign.** `python -m quant_edge.regime.campaign OUTPUT_ROOT` writes,
  without network/env/ambient-time access: `quant/generated/q09/regime_golden_v1.json`
  (golden step vectors/digests and reports), `quant/generated/q09/regime_campaign.v1.json`
  and `.md` (seed `20260712` seeded-series measurements: false-alarm/delay tables, OOD
  measurements, exclusion counts); byte-identical across processes.
