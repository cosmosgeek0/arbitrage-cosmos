## Purpose

Build the §16 validation and anti-overfitting law as a pure deterministic library:
purged/embargoed grouped walk-forward splitting with an untouched chronological
holdout, the §16.2 negative-control battery, exact-rational rank/classification/
calibration metrics, circular-block bootstrap confidence intervals, the §16.3
multiple-testing machinery (trial ledger, CSCV PBO, Benjamini–Hochberg) with explicit
validity gates, a deterministic fixed-point Deflated Sharpe Ratio with a declared
approximation bound, cost/latency stress that can turn an attractive prediction into
abstention, leakage verdicts, and challenger-versus-baseline comparison reports.

Acceptance headline (§20 Q14): a deliberately leaked model is detected and rejected —
both through the temporal lineage audit (declared feature as-of after cutoff) and
through the behavioral battery when lineage is falsified (implausible-skill bound).

Q14 trains no model, admits no data source, computes no live economics and conveys no
action authority; every executable proof is an honest `SYNTHETIC` fixture. Validation
operates on injected sample sets and prediction sets, never on ambient state.

## Code and evidence artifacts

New package `quant/src/quant_edge/validation/`:

- **Sample and prediction contracts.** `ValidationSampleV1` (point-in-time identity:
  sample/symbol/group ids, feature cutoff, label interval end, strata known at
  cutoff, binary outcome and/or gross-edge ratio, quality state) and bounded sorted
  `SampleSetV1`/`PredictionSetV1` with content digests; predictions carry declared
  per-sample feature as-of times and model identity. Unknown outcome stays unknown.
- **Splitting law (§16.1).** `WalkForwardSpecV1` (expanding/rolling, fold count,
  declared max label horizon and feature lookback, embargo ≥ horizon + lookback
  enforced as a contract, minimum train size, holdout fraction) and
  `build_walk_forward_plan`: chronological folds; grouped identity never straddles a
  train/validation boundary; purge (train label interval overlapping validation),
  embargo (backward window before validation start) and group-conflict exclusions
  counted per reason; final untouched holdout whose members never appear in any fold,
  with straddling groups quarantined and counted, and access only through an explicit
  `HoldoutGrantV1` that is recorded in any report that uses it.
- **Negative controls (§16.2).** Seeded deterministic transforms: shuffled labels,
  block-permuted labels within chronological blocks, stale/lagged predictions,
  future-value injection (the deliberate leak, carrying its true as-of times), random
  rank, activity-only baseline from a declared activity column, intentionally
  incomplete data, synthetic false burst, and cost/latency perturbation scenarios.
- **Metrics (§16.4 Q14 subset).** Exact-rational precision/recall at k, top-k recall,
  PR-AUC (average precision), ROC-AUC (Mann–Whitney with tie law), Brier score, ECE
  with declared bins, calibration slope; every metric returns a typed value with
  status and reason (`UNKNOWN` on degenerate support, never a fabricated number).
  Detection lead time, opportunity decay and regime/stage breakdowns beyond declared
  strata are recorded as deferred to the model phases that produce those semantics.
- **Bootstrap intervals.** Seeded circular block bootstrap with declared block
  length, replicate count and coverage; percentile law documented; exact-rational
  endpoints; validity gates.
- **Multiple testing (§16.3).** Immutable `TrialLedgerV1` recording every attempted
  trial including failed/abandoned (automated search counts per trial); CSCV PBO over
  per-block metric matrices with explicit validity gates (even block count, bounded
  combinations) and exact-rational PBO; Benjamini–Hochberg over supplied exact
  p-values; duplicate/perfect-clone trial collapse as the bounded effective-trial
  estimator with its limitation recorded.
- **Deflated Sharpe Ratio.** Exact-rational moments (mean/variance/skew/kurtosis
  machinery), deterministic integer fixed-point Φ and Φ⁻¹ (integer erf series plus
  bisection, bounded loops, declared approximation bound), expected-maximum benchmark
  SR0 over N effective trials, DSR with validity gates (minimum observations, N ≥ 2,
  positive variance adjustment); outputs are `FixedPointV1` with the declared bound,
  never presented as exact.
- **Cost/latency stress.** Explicit scenario contracts (fee/slippage/funding/borrow/
  recovery deltas, latency with declared opportunity-decay law); net-edge
  distributions per scenario; actionable→abstain flip counts; a fixture proves an
  attractive prediction turns to abstention under stress. Missing cost truth stays
  `UNKNOWN` and abstains; it never becomes zero.
- **Leakage verdicts.** Temporal audit (feature as-of ≤ cutoff, loud typed failure
  with bounded violation evidence); implausible-skill bound per declared family;
  shuffled-label sanity (measured skill on shuffled labels must fall inside the
  seeded no-skill band); verdict enum with `REJECTED_TEMPORAL_LEAK` /
  `REJECTED_IMPLAUSIBLE_SKILL` / `REJECTED_CONTROL_FAILURE` /
  `ACCEPTED_FOR_COMPARISON` / `INVALID_INPUT`.
- **Comparison reports.** Challenger-versus-baseline per-fold primary-metric deltas,
  bootstrap interval on the delta, sign counts, verdict (IMPROVES / NO_EVIDENCE /
  WORSE / INVALID), bound to plan digest, trial ledger digest, control verdicts and
  holdout-grant usage; canonical JSON mapping with content digest and a deterministic
  Markdown projection.

Evidence artifacts: golden fixture `quant/generated/q14/q14_validation_golden_v1.json`

## Acceptance conditions

- The leaked-model fixture is rejected through both detection paths and the honest
  baseline passes; the rejection is visible in the committed golden fixture.
- Purge/embargo/group/holdout law holds under property campaigns; the holdout is
  reachable only through an explicit recorded grant.
- Every metric/diagnostic is exact-rational or fixed-point with a declared
  approximation bound; degenerate support yields `UNKNOWN` with a reason, never a
  number; no float exists in any public numeric contract.
- PBO/DSR/BH refuse invalid inputs with typed reasons (“where valid” is a gate, not
  a hope); every attempted trial is ledgered.
- Stress can flip an attractive prediction to abstention; missing cost truth
  abstains.
- All focused/property/contract/safety/accumulated tests, deterministic replay and
  adversarial review pass; immutable `quant/RECEIPTS/Q14.md` exists in the
  implementation commit; a later independently verified acceptance commit records it
  and advances shard state.

## Forbidden shortcuts

- No model training, no calibration fitting, no drift service, no registry/champion
  machinery (Q15), no inference service (Q16).
- No floats in public numeric contracts; no silent rounding; no unbounded loops,
  windows, combination counts or report sizes.
- No missing-as-zero, no fabricated no-skill bands, no tolerance-widening path for a
  failed leak verdict, no “approximately valid” PBO/DSR without the gate.
- No new external data, sockets, env/secret reads, dependency changes or writes
  outside the shard path set; no edit to spine-owned durable state or frozen inputs.
- No claim that any validated quantity demonstrates real edge; Q14 proves the
  falsification machinery only.
