## Implementation boundary

1. **Contracts and limits.** Exact dataclasses/enums for local requests,
   admission, stage lineage, metrics, health and readiness. Bound request/response
   bytes, batch rows, symbols, horizons, queue depth, concurrency and time. Unknown
   values remain explicit.
2. **Protocol.** Strict bounded UTF-8 JSON with duplicate-name and NaN/Infinity
   rejection; frozen schema/version/additional-property/forbidden-key/size
   validation; protocol-canonical bytes and hashes cross-checked with the frozen
   Node implementation. Do not call a serializer RFC 8785/JCS unless all relevant
   number/string/key-order rules are actually met. The existing internal Q
   canonicalizer remains unchanged because it forbids floats and appends LF.
3. **Artifacts.** An allowlisted JSON-only serving manifest pins exact relative
   paths, sizes, hashes, schema names, code/feature/dependency identities and Q15
   model posture. Reject traversal, URI, symlink, device, media/schema/hash/size
   mismatch, pickle/joblib/plugin and ambiguous champion state.
4. **Pipeline.** Parse the generated Q16 raw fixture; invoke Q04 replay rather than
   recomputing book rules; project the eligible book through Q07/Q06 feature owners;
   verify model/calibration availability; build and validate
   `MarketEvidenceEnvelopeV1` and `EdgeAssessmentEnvelopeV1`. Stage digests live in
   Q16 evidence/manifest, not as unknown fields in frozen envelopes.
5. **Service.** Local request operations for assessment, bounded batch, health,
   readiness, model lineage and metrics. Deterministic admission/backpressure and
   error vocabulary; graceful shutdown; errors and metrics never echo raw/private
   payloads. Streaming is `NOT_JUSTIFIED` until a loadable accepted champion exists.
6. **Transport.** Filesystem Unix-domain socket by default in a private directory;
   socket mode `0600`; reject unsafe collisions and cleanup only the socket created
   by this process. Optional TCP accepts literal `127.0.0.1` or `::1` only, never a
   wildcard/hostname/public bind. Frames and handler time are bounded.
7. **Generated kit.** Deterministic Python/Node local clients, manifest, request and
   response fixtures, stage/campaign evidence and integration instructions under
   `quant/generated/q16/**`. Shared Node wiring remains director integration work.
